# Chain of custody

This is a student laboratory chain-of-custody record, not a substitute for institutional procedure. For each item record timestamp, action, person, evidence ID, source, destination, hash, and notes. Create a hash manifest, then append handling actions with `acquisition/manifest.py`. Verification failures stop analysis; originals remain read-only.

Example: `2026-09-15T10:00:00Z | acquired | Student Investigator | EVD-001 | lab VM | evidence store | SHA-256 … | controlled laboratory image`.
