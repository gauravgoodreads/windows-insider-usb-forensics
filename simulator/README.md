# Controlled Windows simulation

These scripts define Experiments A and B. The demo does not need them. To reproduce the scenarios with real Windows artifacts, run them only on a spare Windows test PC or a dedicated test account, with fictional data and a spare USB stick, then collect with `collector/collect_usb_artifacts.ps1`. The scripts perform ordinary local file operations, do not alter forensic timestamps, do not write Registry/event-log claims, and never transmit data. Experiment logs describe intended actions and are metadata—not evidence.
